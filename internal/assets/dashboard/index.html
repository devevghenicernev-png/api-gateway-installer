            Add a TLS domain
            
      
            Adding a domain triggers an ACME challenge (HTTP-01 / DNS-01) — apigw runs it via the CLI today. Pick the issuer your domain is on:
            
      
            Let's Encrypt (public domain, HTTP-01)
            
      
            sudo apigw tls enable letsencrypt \
  --domain api.example.com \
  --email you@example.com
            
      
            DuckDNS (DNS-01, free *.duckdns.org)
            
      
            sudo apigw tls enable duckdns \
  --domain mydomain.duckdns.org \
  --token YOUR-DUCKDNS-TOKEN \
  --email you@example.com
            
      
            Self-signed (dev / staging)
            
      
            sudo apigw tls enable selfsigned --domain my.local
            
      
            Already have one? Use apigw tls add-domain <domain> to expand the SAN on an existing certificate (Let's Encrypt only). Renewal happens automatically via the daily timer.
            
      
            
        
      
            
    
            
  
            

  
  
            
    
            
      
            Webhook setup
            
      
            Paste these into your GitHub repository → Settings → Webhooks → Add webhook.
            
      
            
        
        
        
        
      
            
      
            Once saved, GitHub will fire a ping event — it shows up in the Webhook activity panel within a few seconds. Rotating invalidates the current secret; remember to paste the new one into GitHub.
