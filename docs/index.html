Everything you'd hand-roll, included

One binary. The whole platform.

Stop gluing together certbot, nginx-config-generator scripts, GitHub webhook receivers, and a dashboard nobody maintains.

Git push to deploy

Auto-detects Node, Python, Go, Docker, or static. GitHub webhooks redeploy on push — HMAC-verified, durable bbolt queue, atomic release swap.

TLS that actually renews

Let's Encrypt HTTP-01, DuckDNS DNS-01, or self-signed. systemd timer renewals, atomic rotation so nginx never serves a torn cert.

Live dashboard

SSE-driven UI at /dashboard. Deploy state, log stream, webhook activity, TLS countdowns — no manual refresh. Embedded JS, no Node runtime.

Auth, batteries included

mTLS, JWT (HS/RS/ES/EdDSA + JWKS), SAML, LDAP, BasicAuth. Per-API rules; nginx auth_request routes through the embedded validator.

RBAC + audit + OPA

Hash-chained audit log (SIEM-ready JSON-lines), wildcard permissions, Rego policies against every mutation. SOX-friendly approvals workflow.

Multi-tenancy

Per-tenant path prefixes, RBAC, quotas (MaxAPIs/MaxDeploys), audit slice. One process, many isolated workspaces.

Alerts → wherever you live

Slack · Microsoft Teams · PagerDuty · generic webhook · SMTP. Fires on TLS expiry, deploy failure, GitOps reconcile, queue health.

GitOps + optional Raft HA

Pull config from a git repo on a schedule, or replicate state across peers via Raft. Choose your level of theatre.

Observability built-in

Prometheus /metrics, OpenTelemetry traces, structured slog. Nginx access log tailed live into the SSE feed.

5 commands. 5 minutes.

From clean box to live API.

1
Install the binary
curl -fsSL https://raw.githubusercontent.com/devevghenicernev-png/apigw/main/scripts/install.sh | sudo sh
2
Run the install wizard
sudo apigw install
3
Get TLS from Let's Encrypt
sudo apigw tls enable letsencrypt --domain api.example.com --email me@example.com
4
Connect a GitHub repo
sudo apigw deploy add hello --repo https://github.com/me/hello --port 3000
apigw webhook setup hello   # prints the URL + secret to paste into GitHub
5
Open the dashboard
apigw dashboard open   # https://api.example.com/dashboard
One YAML, the whole gateway

Declarative when you want it.

Every CLI command writes to the same /etc/apigw/config.yaml. Edit by hand, point GitOps at it, or replicate via Raft — same file.

/etc/apigw/config.yaml 
listen:
  https_port: 443
  server_name: api.example.com

apis:
  - name: billing
    path: /api/billing
    port: 8081
    rate_limit: { rps: 50, burst: 100 }
    jwt:
      algorithm: RS256
      jwks_url: https://auth.example.com/.well-known/jwks.json
      audience: billing-api

deployments:
  - name: hello
    repo: https://github.com/me/hello
    branch: main
    port: 3000

tls:
  strategy: letsencrypt
  domains: [api.example.com]
  email: ops@example.com

security:
  rbac_enforce: true
  admin_tokens:
    - { name: deploy-bot, user: ci, token: $APIGW_CI_TOKEN }

alerts:
  slack_webhook: https://hooks.slack.com/services/...
  tls_expiry_warn_days: 30
